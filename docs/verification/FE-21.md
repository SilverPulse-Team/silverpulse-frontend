# Verificación FE-21 — Seguimiento de contramedidas autorizadas

Fecha de verificación técnica: 15 de noviembre de 2026.

## Resultado

| Criterio | Estado | Evidencia |
| --- | --- | --- |
| Solo se registran actividades de un plan existente | Cumple y probado | El formulario queda dentro de cada plan recibido y fija su `plan_id`. El mock rechaza IDs inexistentes y la validación impide plan vacío. |
| La autoría humana queda visible | Cumple | La tarjeta muestra `authorized_by`, título, descripción y rango. El fixture presenta `CMO-DEMO`. |
| La solicitud POST respeta el schema | Cumple y probado | La prueba verifica URL y body con `plan_id`, `completed_at_utc`, `duration_min`, `self_reported` y `notes`. |
| No se afirma que cumplimiento implique aptitud clínica | Cumple | El panel declara que el seguimiento no equivale a condición física ni eficacia clínica. No hay porcentaje ni barra de progreso. |
| El módulo no bloquea el MVP si el endpoint P1 falta | Cumple | Un fallo de GET se representa como extensión P1 no disponible y mantiene visible el alcance P0. |

## Requerimientos demostrados

- Plan existente con título, responsable, fecha inicial/final y conteos completados/programados.
- Actividad programada y actividad completada se expresan como conteos distintos.
- Fecha se convierte a UTC ISO 8601 antes del POST.
- Duraciones cero/negativas y fechas inválidas se rechazan localmente.
- Botón deshabilitado durante envío y errores visibles sin éxito falso.
- El conteo se incrementa únicamente después de una respuesta POST exitosa.
- El provider mock mantiene el cambio solo en memoria y no finge persistencia backend.

## Comprobaciones ejecutadas

- Prueba HTTP del POST y body canónico.
- Prueba mock de conteo antes/después.
- Pruebas de plan ausente, fecha inválida y duración no positiva.
- Suite general: 8 archivos y 33 pruebas correctas.
- `npm run build`, `npm run lint` y `git diff --check` — correctos.

## Límites

- FE-21 es una extensión P1 y no bloquea el alcance P0 del epic.
- No se ejecutó persistencia real contra FastAPI.
- Falta inspección visual/capturas y Pull Request revisado.
